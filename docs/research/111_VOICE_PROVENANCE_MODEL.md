## 1. The Acoustic Grounding Mandate

Vernacular voice intake is a cornerstone of CLINOVA AI’s rural and emergency capabilities. In low-literacy rural health camps and chaotic emergency casualty departments across Odisha, voice recording enables rapid symptom elicitation in Odia, Sambalpuri, Hindi, and Indian English without imposing typing bottlenecks on overburdened nurses.

However, acoustic processing is highly non-deterministic and susceptible to perilous misinterpretations:
- An acoustic drop or phoneme omission can turn *"I am **not** breathless"* into *"I am breathless"*.
- Ambient hospital noise (diesel generators, screaming infants, whirring fans) degrades the Signal-to-Noise Ratio (SNR).
- Complex code-switching (*"Mo chhati pain ho-uchi"* — mixing Odia grammar with English vocabulary) challenges standard language models.

## 2. Acoustic Provenance Architecture & Word-Level Alignment

To make acoustic provenance clinically actionable, text transcripts are not stored as opaque paragraphs. They are parsed into **word-level aligned timecode segments**:

$$\mathbf{S}_i = \left( \text{token}_i, \; t_{\text{start}}^{(i)}, \; t_{\text{end}}^{(i)}, \; c_i, \; \text{speaker}_i \right)$$

Where:
- $\text{token}_i$ is the recognized vernacular word.
- $t_{\text{start}}^{(i)}, t_{\text{end}}^{(i)}$ are millisecond timestamps relative to audio onset ($t_0 = 0\text{ ms}$).
- $c_i \in [0.0, 1.0]$ is the calibrated acoustic confidence score.
- $\text{speaker}_i \in \{\text{PATIENT}, \text{CAREGIVER}, \text{CLINICIAN}, \text{UNKNOWN}\}$ from diarization.

When a physician reviews a clinical narrative on the Doctor Workbench, clicking any extracted symptom (e.g. *"severe retrosternal pressure"*) instantaneously plays the precise 3-second audio slice $[t_{\text{start}} - 500\text{ms}, \; t_{\text{end}} + 500\text{ms}]$ with visual waveform scrubbing.

## 3. Real-World Acoustic Failure Modes & Mitigation Matrix

| Acoustic Phenomenon | Environmental Manifestation | Detection Signal | Epistemic Status & Safe System Response |
| :--- | :--- | :--- | :--- |
| **1. Background Noise** | Rural PHC diesel generator, traffic, whirring ceiling fan. | Spectral SNR $< 12\text{ dB}$; high stationary noise floor. | Audio passed through edge spectral subtraction filter; original raw audio preserved; confidence penalized ($C \le 0.70$); tagged `UNRELIABLE`. |
| **2. Overlapping Speakers** | Anxious son talking over an elderly mother in casualty. | Voice Activity Detection (VAD) detects dual concurrent pitch tracks. | Diarization splits audio into overlapping channels; segments tagged `AMBIGUOUS_SPEAKER`; surfaces prompt asking nurse to attribute narrative. |
| **3. Rural Dialect / Accent** | Western Odisha Sambalpuri dialect or tribal Kui phrasing. | Out-of-vocabulary (OOV) perplexity spike in standard Odia model. | Automatic fallback to regional dialect acoustic adaptation layer; transcribed with warning: *"Regional dialect detected — verify local idiom."* |
| **4. Linguistic Code-Switching**| Rapid alternating between Odia, Hindi, and English medical terms. | Language identification classifier shifts within same sentence. | Multilingual tokenization pipeline preserves English loanwords (*"heart attack"*, *"paracetamol"*) verbatim without phonetic corruption. |
| **5. Negation Misrecognition** | Critical inversion: *"Mo chhati kasta heu-nahi"* (not hurting) parsed as hurting. | Confidence score for negation particle $c_{\text{neg}} < 0.80$. | Strict Clinical Rule: High-acuity symptoms extracted from low-confidence transcripts trigger mandatory visual confirmation card before triage scoring. |
| **6. Truncated Audio** | Microphone cable pulled or app closed mid-sentence. | Waveform abruptly terminates without end-of-turn prosody drop. | Transcript flagged as `INCOMPLETE_RECORDING`; system prompts: *"Patient statement cut off at 4.2s — please re-record."* |
| **7. Inaudible / Muffled Audio** | Hand covering smartphone microphone, severe coughing fit. | Energy level below threshold or non-speech harmonic distortion. | Segment marked `[INAUDIBLE: 00:03.1 - 00:05.4]`; zero clinical concepts extracted from the silent/muffled duration. |

## 4. Voice Provenance Relational Schema

```sql
-- 1. Raw Audio Master Record (Binary media stored on local filesystem or object store)
CREATE TABLE audio_recordings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    case_id UUID NOT NULL REFERENCES cases(id) ON DELETE RESTRICT,
    recording_channel VARCHAR(32) NOT NULL DEFAULT 'CONSULTATION_AMBIENT' CHECK (recording_channel IN (
        'CONSULTATION_AMBIENT', 'PATIENT_DIRECT_VOICE', 'TRIAGE_INTERVIEW', 'TELEPHONE_TRIAGE'
    )),
    file_path VARCHAR(512) NOT NULL,
    file_checksum_sha256 CHAR(64) NOT NULL,
    duration_seconds NUMERIC(6,2) NOT NULL CHECK (duration_seconds > 0.0),
    sample_rate_hz INTEGER NOT NULL DEFAULT 16000,
    audio_format VARCHAR(16) NOT NULL DEFAULT 'WAV_PCM',
    hardware_device_id VARCHAR(64) NOT NULL,
    recorded_by_actor_id UUID NOT NULL REFERENCES users(id),
    recorded_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    retention_status VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' CHECK (retention_status IN (
        'ACTIVE', 'RETAINED', 'PURGED_HASH_ONLY', 'ARCHIVED'
    ))
);

-- 2. Granular Transcript Segments with Acoustic Timecodes
CREATE TABLE audio_transcripts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    case_id UUID NOT NULL REFERENCES cases(id) ON DELETE RESTRICT,
    audio_recording_id UUID NOT NULL REFERENCES audio_recordings(id) ON DELETE RESTRICT,
    segment_index INTEGER NOT NULL CHECK (segment_index >= 0),
    
    start_time_ms INTEGER NOT NULL CHECK (start_time_ms >= 0),
    end_time_ms INTEGER NOT NULL CHECK (end_time_ms >= start_time_ms),
    speaker_tag VARCHAR(32) NOT NULL DEFAULT 'PATIENT' CHECK (speaker_tag IN (
        'PATIENT', 'CAREGIVER', 'NURSE', 'CLINICIAN', 'UNKNOWN'
    )),
    
    detected_language VARCHAR(16) NOT NULL, -- 'or' (Odia), 'hi' (Hindi), 'en-IN' (Indian English)
    raw_transcript_vernacular TEXT NOT NULL,
    english_translation TEXT,
    
    acoustic_confidence NUMERIC(4,3) NOT NULL CHECK (acoustic_confidence >= 0.0 AND acoustic_confidence <= 1.0),
    transcription_engine VARCHAR(64) NOT NULL, -- e.g. 'whisper-v3-multilingual-edge-int8'
    engine_version VARCHAR(32) NOT NULL,
    
    has_human_correction BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 3. Human Correction Ledger (Never overwrites original acoustic hypothesis)
CREATE TABLE audio_transcript_corrections (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    transcript_id UUID NOT NULL REFERENCES audio_transcripts(id) ON DELETE RESTRICT,
    original_text TEXT NOT NULL,
    corrected_text TEXT NOT NULL,
    correction_reason VARCHAR(64) NOT NULL CHECK (correction_reason IN (
        'WRONG_TRANSCRIPTION', 'DIALECT_NORMALIZATION', 'NEGATION_ERROR', 
        'MEDICAL_TERM_TYPO', 'SPEAKER_MISATTRIBUTION'
    )),
    corrected_by_actor_id UUID NOT NULL REFERENCES users(id),
    corrected_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX ix_audio_case ON audio_recordings(case_id);
CREATE INDEX ix_transcript_audio ON audio_transcripts(audio_recording_id, segment_index);
CREATE INDEX ix_transcript_time ON audio_transcripts(audio_recording_id, start_time_ms);
```

## 5. Acoustic Extraction Pipeline Traceability

When an AI extraction module extracts an entity from an audio transcript (e.g. SNOMED CT `267036007` Dyspnea):
1. The resulting `evidence_records` row sets `source_type = 'VOICE_TRANSCRIBED'`.
2. It sets `source_media_type = 'AUDIO'`.
3. It stores foreign key `source_media_id = audio_recordings.id`.
4. It sets `source_snippet_ref = "segment_id:uuid,time:1200-4500ms"`.

If the human user subsequently corrects the transcript, the original transcript remains immutable in `audio_transcripts`, the edit is captured in `audio_transcript_corrections`, and the clinical entity is updated via an append-only modification event. Historical auditory integrity is $100\%$ preserved.
