## 1. Statutory Grounding: BSA 2023 & NMC 2023 Compliance

Under Section 63 of the **Bharatiya Sakshya Adhiniyam, 2023 (BSA)** and Regulations 27 & 28 of the **National Medical Commission (NMC) Regulations, 2023**, electronic evidence generated by autonomous or semi-autonomous software algorithms must carry an unbroken, tamper-evident cryptographic provenance chain.

Every extraction, summary, or advisory insight generated by the AI runtime must be immutably linked to the source observations that gave rise to it.

---

## 2. Mandatory Provenance Metadata Attributes

In strict alignment with Phase 7 Provenance specifications (`RES-107` and `RES-120`), every AI artifact records eight mandatory provenance fields:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       MANDATORY PROVENANCE ATTRIBUTES                       │
├─────────────────────┬───────────────────────────────────────────────────────┤
│ 1. Source Evidence  │ Array of input evidence_record UUIDs fed to context   │
│    References       │ e.g. ["ev-voice-001", "ev-vital-002"]                 │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ 2. Evidence Hashes  │ SHA-256 fingerprint of input evidence set             │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ 3. Model Identifier │ Full model tag (e.g. qwen3-4b-instruct)               │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ 4. Weights Hash     │ SHA-256 hash of local GGUF model binary               │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ 5. Prompt Reference │ Versioned prompt template ID & git commit SHA         │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ 6. Inference Runtime│ Engine name and version (e.g. ollama-v0.3.12)         │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ 7. Validation State │ Deterministic validation code (VALID, REJECTED_*)     │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ 8. Epistemic State  │ Strictly stamped as 'AI_INFERRED'                     │
│                     │ Prohibited from carrying 'VERIFIED' or 'APPROVED'     │
└─────────────────────┴───────────────────────────────────────────────────────┘
```

## 3. Relational Persistence Schema (`ai_inferences`)

```sql
CREATE TABLE ai_inferences (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    case_id UUID NOT NULL REFERENCES cases(id) ON DELETE RESTRICT,
    
    task_type VARCHAR(32) NOT NULL CHECK (task_type IN (
        'EXTRACTION', 'SUMMARY', 'QUESTION_GENERATION', 
        'TRANSLATION', 'NORMALIZATION', 'DRAFT_NOTE', 'ADVISORY'
    )),
    
    -- Provenance & Model Lineage
    model_id VARCHAR(64) NOT NULL,
    model_version VARCHAR(32) NOT NULL,
    weights_sha256 CHAR(64) NOT NULL,
    prompt_id VARCHAR(64) NOT NULL,
    prompt_version VARCHAR(32) NOT NULL,
    runtime_identifier VARCHAR(64) NOT NULL,
    
    -- Source Linkage
    source_evidence_ids JSONB NOT NULL,
    source_evidence_fingerprint CHAR(64) NOT NULL,
    
    -- Output & Telemetry
    generated_payload JSONB NOT NULL,
    calibrated_confidence NUMERIC(4,3) CHECK (calibrated_confidence >= 0.0 AND calibrated_confidence <= 1.0),
    validation_state VARCHAR(32) NOT NULL,
    epistemic_state VARCHAR(32) NOT NULL DEFAULT 'AI_INFERRED',
    inference_latency_ms INTEGER NOT NULL,
    generated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    -- Lifecycle Governance
    lifecycle_state VARCHAR(24) NOT NULL DEFAULT 'GENERATED' CHECK (lifecycle_state IN (
        'GENERATED', 'VALIDATED', 'REVIEW_PENDING', 'ACCEPTED', 'MODIFIED', 'REJECTED', 'SUPERSEDED', 'EXPIRED'
    )),
    
    -- Legal Guardrail: AI can NEVER self-verify
    CONSTRAINT chk_never_self_verified CHECK (
        epistemic_state != 'VERIFIED' AND epistemic_state != 'CLINICIAN_APPROVED'
    )
);

CREATE INDEX ix_ai_inf_case_task ON ai_inferences(case_id, task_type);
CREATE INDEX ix_ai_inf_state ON ai_inferences(lifecycle_state);
```
