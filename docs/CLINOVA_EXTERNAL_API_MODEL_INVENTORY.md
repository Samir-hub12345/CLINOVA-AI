## 3. Discovered Model & Provider Specifications

### Google Gemini 2.5 Flash (`gemini-2.5-flash`)
- **Owner / Provider:** Google LLC / Google DeepMind
- **SDK:** `google-genai` (version in requirements: `>=0.1.1`)
- **Model Family:** Gemini 2.5 Hybrid Reasoning Family
- **Release Date:** June 17, 2025
- **Input Context Window:** 1,048,576 tokens
- **Output Limit:** 65,536 tokens
- **Modalities Supported:** Text, Images, Video, Audio (Input); Text (Output)
- **Official Pricing (Standard):**
  - **Free Tier:** $0.00 input, $0.00 output (Rate limit: 15 RPM, 1,000,000 TPM, 1,500 RPD)
  - **Paid Tier:** $0.30 / 1M input tokens (text/image); $1.00 / 1M input tokens (audio); $2.50 / 1M output tokens (including thinking tokens)
- **Data Policy & Privacy:**
  - **Free Tier:** **Used to train and improve Google products.** Human reviewers may inspect prompt inputs.
  - **Paid Tier:** Not used to train Google products. Data is encrypted in transit and at rest.
- **Current Clinova Status:** Active in backend when `GEMINI_API_KEY` is present and `OFFLINE_DEMO=False`.
